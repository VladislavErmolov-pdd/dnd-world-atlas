# Атлас известного мира — стартовый проект

## Что уже есть
- Интерактивное изображение мировой карты с масштабированием и перемещением.
- Контур Теократии Красной Розы как кликабельная область (первичная оцифровка по красной обводке).
- Переход к увеличению региона.
- Карточка государства с предоставленной пользователем базовой информацией.
- Маркер столицы Ауренхельм (позиция предварительная; её можно уточнить).

## Запуск локально
1. Установите Node.js LTS: https://nodejs.org/
2. Распакуйте архив.
3. Откройте терминал в папке проекта.
4. Выполните:
   ```bash
   npm install
   npm run dev
   ```
5. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Публикация через GitHub + Vercel
1. Загрузите всё содержимое этой папки в корень созданного GitHub-репозитория.
2. В Vercel выберите Add New → Project.
3. Импортируйте репозиторий `dnd-world-atlas`.
4. Framework Preset: Vite. Build Command: `npm run build`. Output Directory: `dist`.
5. Нажмите Deploy.

## Важно
Это первый прототип. Контур Теократии оцифрован приблизительно по красной линии на присланной карте и требует визуальной проверки. Точка Ауренхельма предварительная. Остальные страны пока показаны в списке, но их интерактивные контуры ещё не оцифрованы.
